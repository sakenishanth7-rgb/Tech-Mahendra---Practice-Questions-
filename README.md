# Python Data Analyst Interview Practice

A beginner-friendly Python project covering common Python and Pandas
interview questions for Data Analyst roles.

## Topics Covered

1. List, Tuple and Set
2. Handling Missing Values
3. Removing Duplicates
4. Merging DataFrames
5. Filtering Data
6. GroupBy
7. Finding Second Highest Salary
8. Conditional Columns
9. loc vs iloc
10. Mean, Median and Standard Deviation

## Technologies

- Python
- Pandas
- NumPy

## How to Run

Install the required libraries:

pip install -r requirements.txt

Run the program:

python data_analyst_interview.py

## Purpose

This project was created for practicing Python and Pandas concepts
commonly asked in Data Analyst interviews.
